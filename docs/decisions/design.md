# Decisions — design (룩앤필·디자인 토큰·로고·화면 규칙)

> 앱(app.congre.kr)과 랜딩(congre.kr) 공통 디자인 결정. 새 결정은 맨 위에 추가.

## 2026-10-07 — 디자인 토큰 교체 (롤링페이퍼안)

- **결정**: 앱 전체 색·글꼴·버튼 모양을 롤링페이퍼(영상 방명록)안 기준으로 바꾼다. 바탕 #EEF4FB, 잉크 #1F3C9C(hover #152B73), 글자 #222222·#333333, 보조 글자 #4A5468, 종이 #FFFFFF, 선 #C9D6EA, 입력 테두리 #7F92B8(시안의 #8A9BC0을 입력칸 경계 대비 3:1 기준에 맞게 조금 진하게), 펜 4색(#C62828·#2E7D32·#6A1B9A·#8D4E00), 위험 #A61B1B. 글꼴 Gowun Dodum(UI 전부, 400 하나), Nanum Pen Script(펜 글씨). 버튼 모서리 6px, 카드 직각 1px 선. 움직이는 그라디언트 배경과 유리 효과 삭제. 변수 이름은 그대로 두고 값만 바꿨다(사용처 100곳 이상을 건드리지 않으려고).
- **근거**: 2026-10-06 Ray가 룩앤필 시안 5종 중 2번 롤링페이퍼를 골랐다(캔버스 https://claude.ai/artifact/4ABbmLf1Cg4JwHhtSohuad). 같은 날 390px 실측 화면 점검에서 나온 F1~F12(움직이는 배경, 유리 효과, 글자 간격 벌린 라벨, 영어 장식 라벨, 버튼 끝 화살표, 이모지, 주황, 로고 4종 등)를 Ray가 전부 승인했다. 두 글꼴은 Google Fonts OFL이라 상업·로고 사용이 가능하다(10/06 확인).
- **영향**: 주황 #E8794A와 옛 금색 #c8892c는 앱 화면에서 사라진다(영상의 인트로·아웃트로 글자 색 #c8892c는 렌더 확인이 필요해 다음 테스트 렌더 때). 다크 테마는 C4·C5에서 폐지.
- **출처**: 핸드오프 2026-10-07 5·6장, 화면 점검 시트 F1~F12.

## 2026-10-06 — F 규칙 (모든 화면에서 쓰지 않는 것)

- **결정**: 움직이는 배경, 유리 효과, 장식 그라디언트, 글자 간격 벌린 라벨, 제목의 한 구절만 색 강조, "단어 — 설명" 라벨, 영어 장식 라벨, 버튼 끝 화살표, 이모지, 테라코타 주황, 가운뎃점 나열 메타, "AI" 표현을 쓰지 않는다. 로고는 하나. 채운 버튼 = 주 동작, 테두리 버튼 = 보조, 위험 동작은 떨어뜨리고 색으로 구분. 예시 사진·영상에는 '예시' 표시.
- **근거**: 2026-10-06 화면 점검(라이브 랜딩 실측: 유리 효과 47, 그라디언트 49, 움직이는 요소 52, 글자 간격 라벨 39, 모서리 둥글기 13종)에서 AI가 만든 티가 나는 패턴으로 분류했고 Ray가 F1~F12 전부 승인했다.
- **출처**: 핸드오프 2026-10-07 3·6장.
