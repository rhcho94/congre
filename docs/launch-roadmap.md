# 영업 개시까지 출시 로드맵

> 본 로드맵은 2026-05-18 v2 세션에서 정리된 영업 개시까지 작업 분량을
> 담는다. 새 작업 또는 우선순위 변경 시 같은 커밋에 본 파일 갱신.

## 본 로드맵 작성 배경

본 세션 초반에 운영자 트리거 "결제까지 가는 전체 앱이 완성되어 실제
마케팅·영업을 시작하려면 현 시점에서 어떤 것들을 더 개발해야 하는지"로
출발. 14개 마일스톤 정리 후 운영자가 "코딩으로 구현해야 하는 작업
리스트를 출시까지 로드맵으로" 추가 트리거. 두 영역을 본 문서에 통합.

## 본인 시야 한계 (작성 시점)

- 결제 코드 본문 본 적 없음. 현 시점 0%로 추정
- 일반 사용자 가입·로그인 흐름은 본 세션 S2-03 정찰로 회수 (가입 부재
  확정, 로그인만 존재) — **2026-05-19 v2 P1·P2 완료로 가입 흐름 신설**
- 마이페이지·어드민 대시보드 본 적 없음
- 사업자등록·통신판매업·법무 영역은 운영자 책임 영역

각 항목은 본인 시야 + 추정 혼합. 운영자 시야로 정정 필요할 수 있음.

# Part 1 — 영업 개시까지 14개 마일스톤

## STAGE 1 — 사업·법무 (운영자 책임 영역)

### A1. 사업자등록 / 통신판매업 신고

- 유료 서비스 운영의 법적 전제
- 통신판매업은 유료 결제 시작 시점 신고 의무
- 운영자 결정 영역

### A2. 미성년자 영상 법무 검토

- 1순위 시장(초·중·고 졸업식)이 미성년자 영상 수집·처리
- 부모 동의 절차, 다른 학생 얼굴 비치는 경우 동의, 보존 기간 규정
- 영업 개시 전 가장 큰 법적 리스크
- 변호사 자문 필요

### A3. 약관 v0.1 → 유료 서비스용 갱신

- 현 약관·개인정보처리방침 v0.1 시행 중
- 결제·환불·청구 조항 추가
- 미성년자 동의 절차 명문화

## STAGE 2 — 결제 인프라

### B4. 결제 게이트웨이 선정 + 연동

- **가입 페이지 경로 `/host/signup` → `/signup`** (정찰 결과 /host 단일 파일 비대 회피)
- **users write 위치 src/lib/users.ts 신설** (auth.ts 단일 책임 유지)

- **getIdToken(true) 예방 코드**: 가입 직후 토큰 전파 표준 edge case 대비
