## 4. 목소리 시험에서 알게 된 것

- **느낌표로 끝나는 읽기는 두 목소리·두 문장에서 4번 모두 탈락.** "AI 톤"의 큰 원인으로 본다.
- 세나는 `~`와 `?`에서 합격, 마침표는 행동 유도 문장에서 탈락. 수지는 마침표에서만 합격.
- 라연·고운은 말끝 시험을 하지 않았다(두 문장 이어 읽기 시험만 통과).
- 고운은 문장당 3초 안팎으로 다른 둘보다 느리다. 4편이 가장 긴 이유.
- 문맥 방식에서 다보나(6.9초)·연아(5.4초)는 같은 두 문장을 눈에 띄게 느리게 읽었다.
- 시험 파일: `samples2\`(목소리 9개), `samples3\`(말끝 12개). 스크립트 `tts-test2.mjs`, `tts-test3.mjs`.

## 5. 사고와 고친 것

- **마지막 문장 목소리 끊김(1판 7편 전부).** 음량을 맞추는 단계(loudnorm)가 소리를 192kHz로 내보내는데, 이것을 44.1kHz 효과음과 섞으면 끝부분이 잘렸다. `aresample=44100`을 넣어 고쳤다. Ray가 5편을 듣고 발견했다.
- 재발 방지: `ads3.py`가 렌더 끝에 문장마다 구간 음량을 재고, −22dB보다 작은 문장이 있으면 실패로 끝난다.
- **11/24의 농담 톤 4편(A~D)도 같은 방식으로 섞었다. 끝 카드에서 목소리가 끝까지 나오는지 확인하지 않았다.** 쓸 거면 들어 볼 것.
- 폴더 접근: 이 세션에서 접근 요청이 자동 심사에 여러 번 막혔고, Ray가 채팅에서 직접 승인한다고 쓴 뒤 통과됐다.
