### D 회원 탈퇴 데드락 — 옵션 3가지

1. **차단 범위 축소** — closed 제외, open/rendering만 차단
   - 장점: 코드 최소 변경
   - 단점: 렌더링 직전 race 가능 (closed → rendering 전환 직전 영역)

2. **자동 done 전환** — 클립 0개 상태로 마감 시 즉시 done
   - 장점: 상태 머신 정합
   - 단점: 완성본 URL 없는 done 상태 발생 → 다운로드 페이지·결과 알림 흐름 검증 필요

3. **호스트 이벤트 삭제 기능** — 마이페이지/대시보드에 추가
   - 장점: 사용자 자유도. 데드락 해소
   - 단점: 추가 코드. 기존 결정 (자동 만료 의존) 영역과 충돌. 클립·완성본 삭제 흐름 영역 P4와 거의 동일 코드 패턴 → 재활용 가능

본인 추천 영역: **옵션 1 + 옵션 3 조합**. closed 제외로 즉시 데드락 해소 + 이벤트 삭제 기능으로 사용자 자유도 확보. 옵션 2는 done 상태 흐름 영역 부수 효과 영역 큼.

다만 본인 영역 강제 안 함. 정찰 + 결정 영역은 다음 세션 운영자 영역.
