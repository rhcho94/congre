### 사양 (갈래 4 — Congre 자체 초대 페이지)

| 영역 | 사양 |
|---|---|
| 라우트 | /invite/[eventId] 신규 |
| QR/링크 | /upload/... → /invite/... 변경 ([영상 올리기] 버튼 클릭 시 /upload/[eventId]?token=...로 전달) |
| 호스트 입력 | 환영 문구(welcomeText) + 대표 사진 1장(coverImageUrl) + 갤러리 최대 5장(galleryUrls) |
| events 스키마 | welcomeText, coverImageUrl, galleryUrls 추가 (커밋 1 완료) |
| S3 prefix | events/{id}/clips/..., events/{id}/invite/... 분리 |
| 디자인 | 템플릿 1개 고정, Congre 디자인 토큰 적용 (앰버/골드, Cormorant Garamond italic) |
| status 분기 | open(영상 올리기) / closed(마감 + 버튼 비활성) / rendering(제작 중 안내) / done(완성 영상 보기 → /share/[eventId]) |
| 기존 이벤트 | 빈 필드 fallback (제목·날짜만 미니멀 카드) |
| OG 메타 | 카톡 붙여넣기 시 자동 카드 (공짜 부산물) |
