### 신규 사고 — link.webUrl이 Shotstack URL이어서 "자세히 보기" fallback

- **현상**: 카톡 공유 메시지에서 "자세히 보기" 클릭 시 카카오 초기화면으로 fallback.
- **위치**: `src/app/dashboard/events/[eventId]/page.tsx` `handleKakaoShare()` L261
  ```ts
  link: { mobileWebUrl: event.videoUrl, webUrl: event.videoUrl }
  // event.videoUrl = cdn.shotstack.io/... — 카카오 콘솔 미등록 외부 도메인
  ```
- **원인**: 카카오 피드 공유의 `link.webUrl`은 카카오 콘솔에 등록된 도메인이어야 함. Shotstack CDN URL을 그대로 넣어 미등록 도메인으로 fallback.
- **결정**: 갈래 A(cdn.shotstack.io 임시 등록) 거부, 갈래 B(congre 자체 share 페이지 신설) 채택.
- **격상 이유 (운영자 라인)**: "이건 해결돼야 필드 테스트가 의미 있슴" — P0 차단형.

## 자체 학습 (다음 세션 클로드용)

### 분석·추론 패턴
- **시장별 분기 자동 추정 금지**: 사양 결정 시 "시장별로 다를 수 있다"는 답을 자동으로 내지 말기. 통일 사양 vs 분기 사양은 운영자 결정 영역.
- **외부 콘솔 메뉴 트리는 추정 안내 금지**: 카카오·Firebase 등 외부 콘솔 메뉴 경로 안내 시, 운영자 화면 캡처 먼저 받은 후 안내. 추정으로 메뉴 트리 제시 X.
- **dead code = 기능 미구현 등식 주의**: DECISIONS에 "구현 예정"이라 적혀 있어도 실제 호출 코드가 없으면 미구현. 두 단계 검증 (문서 확인 → 코드 grep).
- **비용 비교표에서 0원 항목 명시**: egress $0 같은 항목은 "0" 또는 "$0/GB"로 명시. 빈칸 두지 말기.
- **임시 회피 vs 본질 해결 갈림길에서 도메인 제약 먼저**: "이게 동작 안 하면 데이터 자체가 의미 없는가"를 먼저 확인. 이 질문에 "그렇다"이면 임시 회피 기각.
- **사양 항목 간 의존성 명시**: 결정 항목 작성 시 "이 결정은 저 결정에 의존"을 함께 적기.

### 운영 패턴
- **세션 길어지면 능동적 매듭 제안**: 컨텍스트가 길어지고 결정이 쌓이면 "여기서 핸드오프 작성 후 다음 세션에서 작업할까요?" 능동 제안. 운영자가 매번 짚게 두지 말기.
