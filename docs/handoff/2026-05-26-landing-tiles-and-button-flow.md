## 결정 이력 메모

- **이미지 톤 정정 사고**: 다크 시네마틱 프롬프트로 4장 만들었는데 운영자가 "어둡고 어색"이라며 레퍼런스 이미지 4장 제공. → 페이지 메인 톤이 다크라서 모든 이미지도 다크여야 한다는 추론에 갇혀, 운영자 1순위 시장(졸업식·결혼식·일반 행사 진짜 사진)의 실제 모습을 확인 안 했음. 레퍼런스 먼저 달라고 했어야. **다음부터: 시각 톤 결정 시 운영자에게 레퍼런스 1순위로 요청.**
- **"4곳" 카운트 오류**: 채팅 클로드가 `/terms`·`/privacy` 사용처를 "4곳"으로 명시했는데 실제는 2곳씩 총 4곳 (헷갈리는 표현). CC가 정확히 잡아내고 보고. **다음부터: 합산 수치 보고 시 한 번 더 카운트 검증.**
- **사전예약 모달 이미 작동 발견**: 채팅 클로드가 4번(학교/기업 문의)을 "모달 재활용 + 라디오 자동 선택" 코드 작업으로 잡았는데, CC 정찰에서 이미 `configureSignup(variant)` 함수가 작동 중이고 variant별 사전 체크 로직 이미 구현됨을 발견. → 작업 범위 축소(3번·5번만). **다음부터: 정찰 단계에서 JS 위임 핸들러까지 보면 같은 누락 방지.**
- **`navigator.share` 데스크탑 지원 발견**: 데스크탑 크롬 최신이 `navigator.share` 지원 → 윈도우 OS 공유 시트 출현. "토스트 안 뜸"이 사고 아닌 의도된 분기 동작. **다음부터: `navigator.share` = 모바일 전용으로 단정하지 말 것.**
- **카톡 인앱 브라우저 함정**: 폰에서 토스트만 뜨고 시트 안 떴다는 보고 → 직접 브라우저로 다시 시도 시 시트 정상. 카톡 안 인앱 브라우저가 `navigator.share` 미지원 케이스. 1순위 시장(졸업식) 학부모·교사 단톡방 공유 경로에서 빈번할 가능성. → 현 시점은 fallback 유지(YAGNI), 필드 테스트 후 카카오 JavaScript SDK 도입 검토.
- **도메인 `congre.kr` 미연결 재확인**: 운영자가 "이미 연결되어 있을 것"이라고 했으나 채팅 클로드가 외부 fetch로 DNS 응답 없음 확인 → 운영자 Vercel 콘솔 Domains 탭 확인 결과 없음. 도메인 미연결 상태 유지. 이번 사이클에선 vercel.app URL로 박고 도메인 연결 후 일괄 치환 예정.

## 알려진 이슈

### 카톡 인앱 브라우저 `navigator.share` 미지원 (신규)
- **현황**: 카톡 안 링크 클릭으로 페이지 열린 경우 `navigator.share` 미지원 → "행사 호스트에게 전달" 클릭 시 토스트 + 클립보드 fallback만 동작 (OS 공유 시트 안 뜸).
- **격상 트리거**: 필드 테스트 1회차 후 카톡 공유 빈도 데이터 / 1순위 시장(졸업식) 본격 진입 시점 / 운영 사용자로부터 "공유가 어렵다" 신고.
- **처리 후보**: 카카오 JavaScript SDK 도입. 도메인 `congre.kr` 연결 이후가 자연스러움 (카카오 디벨로퍼스 도메인 등록 시 vercel.app보다 자체 도메인이 깔끔).

### `/terms`·`/privacy` 본 앱 절대 URL 임시 사용 (신규)
- **현황**: 도메인 미연결 상태이므로 `https://congre-three.vercel.app/terms`·`/privacy`로 박음.
- **격상 트리거**: 도메인 `congre.kr` Vercel 연결 완료 시점.
- **처리**: 도메인 연결 후 `https://congre-three.vercel.app/` → `https://app.congre.kr/`로 일괄 치환 (sed 1줄).
