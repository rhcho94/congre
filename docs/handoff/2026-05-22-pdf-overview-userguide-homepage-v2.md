## 본 세션 사고 학습 6건 (본인 영역)

### 사고 1: 핸드오프 정찰 없이 단정

- δ 작업 후 외부 자료 영역 "PDF 작성 = CC 영역 (Python 스크립트 의뢰)" 추천
- 정찰 결과 실제 운영 방식: 채팅 클로드가 컨테이너에서 직접 ReportLab으로 작성·빌드, 매번 새로 작성
- **학습**: 외부 자료(과거 핸드오프) 회수 없이 "재생성 가능 vs 일회용" 단정 차단. 운영 방식 정찰부터 본인 시야 영역

### 사고 2: "→" 글리프 사고 재발현

- 1차 발현: 앱소개서 빌드 시 본문 "외주 2주 → 자동 5분" + 박스 "↓" 사용 → □ 출력 → 시각 확인 → 텍스트 대체로 정정
- 학습했음에도 합본 사용 가이드 빌드 시 4개 위치에서 "→" 재사용 → 사후 sed로 모두 텍스트 대체
- **학습**: 학습 영역도 작업 진입 시 체크리스트로 만들지 않으면 재발. 다음 PDF 작업 시 본문 작성 후 `grep "→"` 자동 점검 영역 본인 의식 강화

### 사고 3: placeholder 함수 영문 폰트만 전제

- `draw_screenshot_placeholder` 헬퍼 작성 시 영문 자간 라벨만 전제
- 한글 라벨 "[ 회원가입 화면 ]" 사용 시 □ 출력
- 함수에서 한글·영문 자동 전환 패턴 사용으로 정정
- **학습**: 헬퍼 함수 작성 시 본인이 사용한 예시(영문)만 보고 일반화 안 함. **모든 텍스트 영역은 한글·영문 자동 전환 패턴 적용**이 안전

### 사고 4: CC 프롬프트 "신규 추가" 표현이 빈 상태 신호로 읽힘

- 본인이 운영자에게 폰트 8개 + py 스크립트 2개 전달
- 운영자가 폰트·py 모두 PC에 저장 완료
- 본인 CC 프롬프트 "scripts/pdf/ 신규 디렉토리 + 폰트 8개 + py 스크립트 2개 신규 추가" — "신규" 표현이 CC에 빈 상태 신호로 읽힘
- CC가 scripts/pdf/fonts/ 디렉토리 확인 안 함 → 폰트 직접 다운로드 시도 → GitHub HTML 다운로드 사고 → Google Fonts CSS API 데이터 .ttf 저장 (실제로는 추적용 더미 영역) → 매직 바이트 정체 불명
- **학습**: 운영자 외부 작업으로 파일 들어가는 영역은 CC 프롬프트에 **"이미 저장 완료 상태이므로 다운로드·생성 금지"** 명시 필수. 폰트·이미지·바이너리 영역 모두 동일 패턴

### 사고 5: 운영자 명시 답 없이 사고 영역 단정

- 운영자가 폰트 저장 완료 답함
- 본인이 "운영자가 안 했을 가능성" 단정으로 진단 시작
- 운영자 한 마디로 정정
- **학습**: 운영자 명시 답 받기 전 사고 영역 단정 차단. 명시 답 패턴 사용

### 사고 6: CC 작업 시간 영역 사전 안내 안 함

- CC churning 8분 영역에 사용자 알림 안 옴
- 보통 1~2분이 표준 영역인데 8분 영역은 사고 신호
- 본인이 CC 작업 시간 영역 사전에 안내 안 함
- **학습**: 다음부터 CC 작업 후 보고가 5분 이상 안 오면 사고 의심 영역 운영자에게 사전 안내
