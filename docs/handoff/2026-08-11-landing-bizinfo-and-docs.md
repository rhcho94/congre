2. **`decisions/notifications.md:93`이 `hello@congre.kr`을 발신 주소 후보로
   기재** — 결정 자체는 틀리지 않았다. `congre.kr`은 SPF·DKIM이 검증돼 있어
   **발송은 가능**하고 못 하는 것은 수신뿐이다. 다만 `emailChannel`에 reply-to
   확장이 있어, 나중에 이 줄을 보고 발신 주소를 `hello@`로 바꾸면 **답장이
   수신 불가 주소로 간다.** 한 줄 주석으로 막히는 문제 — 다음 코드 세션 큐잉.

   오름차순. 예정 블록이 맨 아래 있던 기존 구조를 유지한 결과다. 다른 문서의
