# 2026-07-03 핸드오프 — 이메일 인증 발송 실패 무한루프 해결 + 웨딩 라이브 방향 결정

## 한 줄 요약
이메일 인증메일 발송 실패 무한루프를 해결(Firebase 승인된 도메인에 app.congre.kr 누락이 원인, stale값 congre-three.vercel.app만 등록돼 있었음). 코드 무변경, Firebase 콘솔 도메인 추가로 해결. 더불어 FGT 신호 약함 → 국내 웨딩 라이브 전환 방향 확정, 해외/영어전체화/네이티브앱은 국내 검증 후로 보류.

## 이번 세션 사고 진단 (프로덕션, 해결 완료)
- **증상**: 호스트 계정(rhcho94@gmail.com 등)에서 이메일 인증메일 발송 실패 무한루프. 가입→"이미 가입됨", 로그인→성공, 대시보드→"인증 필요", 재발송→"재발송 실패". 지인 Gmail도 동일. 메일이 스팸함·mail-tester(중립 수신서버)에도 안 옴.
- **진짜 원인**: Firebase Auth 승인된 도메인(Authorized domains) 목록에 현재 서비스 도메인 app.congre.kr이 누락. stale값 congre-three.vercel.app만 Custom 등록. → 인증메일 continue URI가 app.congre.kr인데 승인목록에 없어 Firebase가 발송을 400(auth/unauthorized-continue-uri)으로 거부.
- **증거 체인**: "재발송 실패"(send-side 신호) → mail-tester "이메일 받지 못함"(발송 자체 실패, 도달성 아님) → Vercel 로그 에러 0건(발송이 브라우저→Firebase 직접 호출이라 서버로그 안 남음) → 브라우저 콘솔 POST accounts:sendOobCode 400 + Domain not allowlisted by project (auth/unauthorized-continue-uri) → Firebase 콘솔 승인된 도메인에서 app.congre.kr 누락 확인.
- **해결**: Firebase 콘솔 → Authentication → 설정 → 승인된 도메인 → app.congre.kr 추가. 코드 변경·CC 불필요. rhcho94 계정 인증링크 클릭까지 완료해 루프 탈출 확인.

## 이번 세션 방향 결정 (코드 무변경, 결정만)
- FGT 발송했으나 지인 반응 약함 → 국내 웨딩(카페·블로그 침투 마케팅)으로 채널 전환, 결제 붙여 라이브. 결제(PG)가 "대기"에서 "핵심 경로"로 승격. 1순위 시장 학교(미성년)→웨딩(성인) 이동으로 미성년자 법무 리스크는 학교 진입 시점으로 미룸.
- 해외·영어전체화·네이티브앱은 "국내 웨딩 검증 후" 조건부 보류. 근거: 영어 UI는 해외의 5%, 나머지(Stripe 등 해외결제·법무·마케팅채널·경쟁)가 진짜 벽. 네이티브앱은 게스트가 QR→브라우저라 앱 설치 안 함 + Apple 4.2(웹 껍데기 반려) 리스크.
- 유일한 지금-후보: 게스트 촬영화면만 한/영 토글(i18n A단계) — 국내 웨딩(외국인 하객)+해외 첫 디딤돌 이중효과. 웨딩 몇 건 신호 보고 착수.
