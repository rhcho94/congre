  자체는 사고 없이 완결. 회귀 사고(2①)는 코드 결함이 아니라 사양 결함.
  패턴 유지.

- **API 미확증 속성 처리**: rich-text `background.opacity`가 caption에서만
  확인됐던 영역. 사양에 박되 폴백을 미리 합의하고 들어감. stage 렌더로
  실증 — 운영자 보고에서 별도 에러 없으니 background.opacity는 rich-text도
  지원하는 것으로 확정.

- **사양 부재의 가능성**: 본 세션 초대장 영역은 "사양 표류"가 아니라
  "사양 부재"였음. 사양 표류 = 사양이 있었는데 변경됐다, 사양 부재 =
  처음부터 없었다. 운영자 회상이 모호한 표현("어디선가 사라진 듯")일
  때 두 가능성 다 검토. 코드/결정 이력 시간순 정찰로 구분 가능.
