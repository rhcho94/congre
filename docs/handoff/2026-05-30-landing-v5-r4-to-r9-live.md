## 본 세션 학습 룰 후보 (CLAUDE.md 학습 룰 섹션 격상 후보)

본 세션 누적 룰 후보 3건. 본 세션 즉시 격상 안 함(YAGNI 영역 — 1회 관측). 본 핸드오프에 박아 다음 세션 검증·격상 영역.

1. **CD zip은 index.html 갈음 X, 별도 파일로 저장 가능** — CD 캔버스 작업 결과 zip export 시 `Landing v5.html` 같은 파일명으로 저장됨. Vercel은 `index.html` 만 라이브 박음. R 사이클 마감 시 zip 풀어덮기 후 `index.html` 본문 검증 단계 의무화. 검증 방법: `Select-String -Path "deploy\index.html" -Pattern "신규 카피 한 단어"`. 본문이 V5 카피와 일치 안 하면 `Landing v5.html` 같은 파일 존재 점검.

2. **외부 작업 단계 정정 진입 전 가설 검증 단계 박을 영역** — 본 세션 이중 폴더 사고 정정 시 본인이 "deploy/deploy 안 내용물 = V5"라 추측 → 검증 없이 정정 진입 → 같은 사고 반복. 다음부터 정정 흐름 진입 전 "확인할 영역" 한 단계 박기. 본 사고는 `Select-String` 한 줄로 즉시 잡혔을 영역.

3. **CTA 버튼 의도 평가 시 단일 사용자 좁게 가정 X** — R8 사이클에서 "행사 호스트에게 전달" 버튼을 본인이 어색하다고 평가. 호스트 = 단일 사용자로 좁게 추측. 실제는 호스트 + 호스트 후보 referral 영역. 페이지 본 사람 영역 단일이 아닌 다수 가정으로.
