## 이 세션 학습
- **핸드오프의 "가설"을 "확정 진단"으로 읽지 말 것.** "SPF alignment"는 추정이었는데 확정처럼 취급해 이메일 트랙에서 두 번 헛짚음. 핸드오프 문장은 사실/가설을 구분해 읽는다.
- **세션 중 CC 직접 커밋은 코난에 해시라도 보고돼야 함.** `84a31b5`(문서 커밋)를 코난이 몰라 D2 종료 판정을 3커밋 기준으로 셀 뻔함. 결과적으론 무해했으나(문서 전용) 오너십 룰상 모든 커밋은 코난 경유.
- **터미널 출력의 잘림 ≠ 파일 손상.** CC diff 출력이 화면폭에 잘려 본문 깨진 것처럼 보였으나 scout 원문 확인 결과 파일은 온전. 표시층과 파일층을 구분해 확인.
- **`git --stat`의 +N 주의.** 수정된 줄은 삽입·삭제 양쪽 계상되므로 막대 문자 단순 합산과 어긋날 수 있음(오류 아님).
