### R1 — Hero 섹션 재설계 (CD 작업)

- **메인 카피**: "행사가 끝나기 전에, 영상이 나옵니다." (운영자 어감 갈래에서 "나옵니다" 확정)
- **서브 카피**: "각자 폰으로 10초씩. AI가 실시간으로 한 편을 만듭니다."
- **메트릭**: "1,200+ 학교 · 평균 편집 시간 5분" (이전 12분에서 변경 — 운영자 확인 결과 12분도 실측 아닌 영업용 placeholder. 5분으로 통일)
- **레이아웃**: 좌측 카피 / 우측 핸드폰 영상 50:50, 100vh 1페이지 단위
- **학생 사진 띠**: 영상 우측 끝에 영상과 겹치는 세로 스크롤 카드 리스트로 복원 (#09·#17·#16·#15·담임·#14·#13·#12·#11 등). 카드 배경 반투명 (rgba 0.25 영역). 실시간 클립 업로드 시각화가 핵심 BM 메시지
- **AI 편집 진행률 UI**: CONGRE AI · 자동 편집 + 6개 항목 진행률 (현 상태 유지)
- **폰트**: Pretendard 산세리프 (Cormorant italic 제거, nav 로고 Congre는 예외 — 브랜드 마크 룰)

### R2 — Why now 섹션 재설계 (CD 작업)

- **메인 카피**: "외주는 2주, Congre는 5분." ("외주는 2주"에 취소선 — CD 자체 디테일)
- **서브 카피**: "편집자 없이, 기다림 없이, 행사 끝나기 전에."
- **키커**: "새로운 방법"
- **좌우 시각 표현**: 일러스트 만화 방식
  - 좌측 (예전 방식): 편집자 한숨 + 책상 영상 파일 더미 + "2주 WAITING" 달력 + Z 졸음 표시
  - 우측 (Congre): 스톱워치 "5분" 중앙 + 폰들이 궤도로 도는 모션 + 골드 액센트
- **카드 3-bullet**: "행사 다음 주" / "행사 당일" 등 "식" → "행사" 전체 치환 적용

### R3 — How it works 섹션 재설계 (CD 작업)

- **메인 카피·서브**: 기존 그대로 ("세 단계만으로" / "호스트가 링크만 공유하면 됩니다. 나머지는 참여자와 Congre AI가.")
- **키커**: "이렇게 동작합니다" (HOW IT WORKS 영어 → 한글로 통일)
- **카드 톤**: 크림 배경 (#f5efe4 영역) + 다크 페이지 (#0c0b09) 강한 대비
- **Card 01** — 손가락이 단톡방 링크 클릭 모션 (GSAP timeline 4초 루프)
- **Card 02** — QR 스캔 + REC 촬영 (2단계 묶음). 운영자가 셀카 → QR 전환 결정. 시간 라벨 "10초/인" 유지 (촬영 기준)
- **Card 03** — 클립 6개가 폰으로 모이는 모션 + 골드 파티클 burst ("모이기" variant 확정, "쌓이기" 폐기). 클립 비율 세로 9:16 (셀카 영상 비율 반영)
- **V1·V2·V3·V4 진행**: V1 정적·추상 사고 → V2 GSAP 명시 + 2 variants 요청으로 회피 → V3 Card 03 토글 제거 + 클립 세로 비율 정정 → V4 Card 03 카드 높이 정정 (카피가 카드 영역 밖 흘러나옴 사고 해소)

## 본 세션 학습 룰 (CLAUDE.md 학습 룰 영역 누적용)

### 1. CD는 "AI slop" 패턴으로 수렴 (Anthropic 본인 공식 인정 영역)
명시적 부정·긍정 지시 없으면 Inter font / 흰-보라 그라데이션 / 정적 일러스트 / Linear·Stripe lookalike로 회귀. 운영자 R3 V1 정적 시안이 정확히 이 패턴. 회피 패턴: GSAP·Anime.js 등 라이브러리 명시 요청 / variants 2개 비교 요청 / "avoid Inter/Roboto/generic" 부정 + 구체 대안 둘 다 박기 / 참고 스크린샷 첨부

### 2. CD 프롬프트 길이 — 짧은 스캐폴드 + 인라인 코멘트 흐름
첫 영어 500단어+ 프롬프트는 막힘 위험 (직전 CD backfill 사이클 학습 룰). 200단어 4요소(Goal/Layout/Content/Audience) 스캐폴드 + 인라인 코멘트로 디테일 잡는 게 검증된 패턴. 본 R1·R2 성공 = 짧은 스캐폴드. R3 V1 길게 박은 모션 명세도 CD가 무시 → 결국 GSAP 명시·variants 요청으로 회피

### 3. CD가 압축·축약했을 때 운영자 원안 의도 사라졌는지 점검
R1에서 CD가 학생 사진 스크롤 띠를 "LIVE 업로드 17/24명" 정적 카운터로 압축. 채팅 클로드가 "더 깔끔한 해석"이라 평가했으나 운영자 BM 본질(실시간 클립 올라오는 움직임)이 사라짐. **추측 어긋남 영역**: 다음부터 CD 축약 시 운영자 원안 의도 점검부터

### 4. docs 박힌 숫자도 출처 확인 필요
PROJECT.md "평균 편집 시간 12분"이 실측인지 placeholder인지 확인 없이 사실로 가정 → 5분 vs 12분 충돌 사고. **다음부터: docs 숫자도 운영자에 출처 확인 후 처리**

### 5. CD 영어 vs 한국어 프롬프트
영어 prompt가 토큰 효율·internal reasoning 측면 약간 유리. 출력물 안 한국어 카피는 그대로 한국어로 유지. 본 사이클 R2부터 영어 프롬프트로 전환
