## 코드 변경 내역 (`f9f54c9`)

신규 2파일. **기존 파일 수정 0건.**

### `src/app/payment/success/page.tsx`

쿼리 `paymentType`·`amount`·`orderId`·`paymentKey`를 읽어
`confirm` → `render/start` → 이벤트 페이지 이동.

- **`authStateReady()` 대기** — 이 페이지는 토스에서 리다이렉트로 새로
  열리므로 Firebase 로그인 복원 전에 `currentUser`가 null일 수 있다.
  대기 없이는 결제가 성사됐는데 `confirm`이 호출되지 않아 승인 대기로
  남는 경로가 열린다. **간헐 실패라 테스트에서 안 잡히는 종류다.**
- **`called` ref 가드** — StrictMode 이중 실행으로 승인이 두 번 나가는 것 차단
- **에러 3갈래** — `CLIP_COUNT_CHANGED`(409) / `ORDER_NOT_PENDING`(400) / 그 외
- **`error ?? code ?? "UNKNOWN"` 순으로 읽음** — `confirm/route.ts:111`이
  토스 응답 본문을 그대로 400으로 흘려보내 우리 `error` 키가 없을 수 있다.
  **실제 카드 거절이 이 경로로 온다**
- **`render/start`만 실패한 경우 별도 상태** — 결제 완료 사실을 명시하고
  이벤트 페이지 링크 제공. `alert()` 미사용
