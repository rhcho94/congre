## ★ 확정된 디자인 시스템 (이 트랙의 핵심 — 절대 안 새게)

### 방향
- **Partiful 방향** 확정. (운영자 선택: Weverse vs Partiful 두 극 중 Partiful = 발랄·재미·또래 감성 우세.)
- 운영자가 직접 수집한 레퍼런스: **Weverse + Partiful** (스크린샷 4장 제공 + 운영자 보유 10장).
  - Partiful: 히어로(다크+비비드 그라데이션+그레인), 이벤트생성(라이트 진주빛), 프로필메뉴(라이트).
  - Weverse: 다크 + 컬러 글리프 아이콘 + 둥근 카드 + 하단 탭바 + 그라데이션 FAB.
- **버리는 것(옛 톤)**: Cormorant 세리프, 골드/앰버(#c8892c), 장식 과다, 필름누아르 럭셔리.

### 라이트/다크 = B 하이브리드 (확정)
- **다크**: 히어로, 결과물(완성 영상), 게스트 업로드 — *영상이 주인공이라 다크가 돋보임*.
- **라이트 진주빛(pearlescent)**: 대시보드, 이벤트 생성 폼, (추정) 인증·마이페이지 — *입력·정보라 라이트가 편함*.
- 두 톤이 같은 shimmer+grain 언어를 공유, 다크냐 라이트냐만 다름.

- 신고번호는 아직 없으니 그 전엔 신고번호만 빼고 나머지 준비 가능.
- **랜딩 리뉴얼 작업에 이 푸터 정비를 포함시킬 것**(중복 작업 방지). L8(약관·개인정보 절대경로 링크)도 같은 푸터.

## 주의사항 (컨텍스트 새지 않게)
- **CD 결과물 가져오는 법**: CD는 별도 인스턴스(컨텍스트 격리). 채팅으로 가져오려면 — (검토용) **스크린샷/화면녹화**, (구현용) **Standalone HTML export**. 디자인 핸드오프 URL(`api.anthropic.com/v1/design/...`)은 **73MB 초과로 fetch 불가** → 재시도 금지.
- **버려진 브랜치**: 본 세션에 '작동 원리'를 **새로 동적 제작**하는 CD 프롬프트를 한 번 보냈으나, 데모가 기존 코드임이 밝혀져 **무효**. CD가 그 프롬프트로 만든 '작동원리' 산출물이 있어도 쓰지 말 것(기존 코드 색교체가 정답).
- **L8 / L9 (랜딩 git-외부 수동 수정분)**: L8 = index.html 푸터 약관·개인정보 절대경로(`https://app.congre.kr/terms`·`/privacy`), L9 = pricing.html 계산기 섹션. **CD zip/새 배포로 덮으면 소실.** 랜딩 적용 시 반드시 보존·재적용. 백업: `pricing_pre_calc_backup.html`.
- **모션 검증**: 동적 요소는 정적 캡처로 검증 불가 → 화면녹화 또는 (0%·중간·100%) 3컷.
- **트랙 분리**: 랜딩(git 외부, 수동/zip, app.congre.kr 아님 = congre.kr) ≠ 앱(git, CC, app.congre.kr). 한 사이클에 섞지 말 것. CD 시각 생성 단계만 두 화면 같이 가능.

## 본 세션 학습 (한 줄씩)
- **화면 등장 시 "기존 구현 vs 새 CD 시안" 먼저 확인**: LIVE·EDITING 데모를 새 CD 작업으로 오인(두 번 헛발). CD 캡처 흐름 중이라 묶어버림. 운영자가 "기존 구현"이라 바로잡음.
- **디자인 핸드오프 URL은 채팅 클로드가 못 엶**(73MB). 검토는 스크린샷, 구현은 HTML export.
- **CD는 명시 안 하면 안 뺌**: 하단 고정 바를 "추가"했더니 기존 CTA를 안 빼 중복 발생 → "교체/빼기" 명시 필수.
- **CD는 라이브러리(GSAP) 명시해야 모션** (이번엔 데모가 기존이라 무효화됐지만 룰 유효).
- **디자인 레퍼런스 운영자 선수집(Weverse+Partiful)이 AI slop 회피에 결정적** — 막연한 "모던하게"가 아니라 구체 레퍼런스가 시스템을 날카롭게 함.
