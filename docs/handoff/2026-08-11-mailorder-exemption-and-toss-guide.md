## 토스 공식 가이드로 확정된 것 (문서: "홈페이지 결제경로 제작 가이드", 2024-07-01)

**심사 캡처는 6단계다.** 앞 세션까지 ②③⑤⑥ 4개로 세고 있었으나 실제로는
①~⑥이며 **④(로그인/회원가입)가 목록에서 누락돼 있었다.**

| 단계 | 요구 | Congre 현황 |
|---|---|---|
| ① 가맹점 정보 기재 | 표지에 상호명·사업자번호·URL·**테스트 계정 ID/PW** | 테스트 계정 미준비 |
| ② 하단정보 캡처 | 상호명·대표자명·사업자등록번호·통신판매업신고번호·사업장주소·**유선전화번호** | 6항목 중 유선번호 미보유, 통신판매업은 면제 표기로 대응 |
| ③ 환불규정 캡처 | 환불 규정이 **웹페이지에 렌더된 화면**. 무형상품 예시는 이용약관 조문 자체를 캡처한 것 | 약관 제10조의3 미적용 |
| ④ 로그인/회원가입 | 테스트 계정 로그인 과정. 비회원 구매 가능 시에만 생략 | Congre는 가입 필수라 생략 불가 |
| ⑤ 상품선택/구매과정 | 상품/서비스의 **명칭·이미지·상세설명·금액**이 결제페이지·결제창에서 흐름으로 확인될 것 | 유료 플랜 `comingSoon` 잠금 상태 |
| ⑥ 카드결제경로 | 카드 결제창 화면 | 결제 연동 코드 0건 |

**캡처 형식 요건 (놓치면 전부 재촬영)**
- PPT 형식 필수
- 북마크바 없이 **도메인이 보이도록** 캡처
- **PC 시계까지 함께 캡처** — 카드사가 시간 흐름으로 조작 여부 판단
- 비씨카드는 결제 직전까지 확인이 필요해 카드사 인증 화면까지 캡처

**해소된 미확인 항목**: "토스 테스트 키만으로 위젯 연동을 어디까지 진행
가능한가" → **가이드 4페이지 6번이 테스트용 결제창으로 연동돼도 심사
가능하다고 명시.** 테스트 연동 가이드 링크도 제공된다
(`docs.tosspayments.com/guides/payment-widget/integration`).

**따라서 심사 재료에 필요한 것은 "결제 완결"이 아니라 "결제 흐름 캡처"다.**
서버 금액 산출·환불 처리·정산은 실서비스 요건이지 캡처 요건이 아니다.

  테스트 키 허용 여부 — 세 가지가 모두 가이드 한 번 정독으로 확정됐다.
  그 전까지 세 세션에 걸쳐 추정으로 다뤄왔다.
- **"실측하라"는 지시가 누락분을 잡는다.** L14를 자체 추정 금지·실제 카운트로
  지시한 결과, 이번 세션분 1건 외에 미등재 2건이 함께 발견됐다.
- **두 문서의 번호 관례 차이는 이미 기록돼 있었다.** `legal.md`는 블록 내
  지역 번호, `landing.md`는 전역 일련번호. 앞 세션 핸드오프에 적혀 있었으나
  참조하지 않아 불필요한 확인 정찰을 한 번 더 돌렸다.
- **터미널 출력 뭉개짐 ≠ 파일 손상 (재확인).** 랜딩 편집 후 인용문이 중간
  누락된 채 표시됐으나, 바이트 증분 +52가 교체 문자열 차이(65−13)와 정확히
  일치해 파일 무결성이 확인됐다. **산술 대조가 육안 인용보다 빠른 증거였다.**
